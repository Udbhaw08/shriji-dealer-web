# Capacitor Native Mobile Sync Workflow

## Commands
- `npm run build`: Builds web assets, syncs documentation, and updates native folders.
- `npm run cap:sync`: Copies `dist/` output to `android/` and `ios/` native projects.
- `npx cap run android`: Launches Android emulator or connected device.
- `npx cap run ios`: Launches Xcode iOS simulator.

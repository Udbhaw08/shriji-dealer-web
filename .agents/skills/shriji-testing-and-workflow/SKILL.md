# Shriji Testing & Workflow Skill

This skill outlines the standard development commands, regression test suites, documentation synchronization, and release guidelines.

## Daily Development Commands

```bash
# Start Vite local development server (with Zoho API middleware)
npm run dev

# Run automated regression test suite (pricing calculations, dealer rules)
npm test

# Build production bundle (automatically runs generate-codebase-doc.mjs first)
npm run build

# Synchronize and regenerate CODEBASE.md
npm run docs

# Audit live Zoho Commerce items against CSV benchmark
node scripts/audit_prices.mjs
```

## Hard Workflow Rules

1. **Test Before Complete**: Whenever pricing calculation, roles, or API endpoints are modified, always execute `npm test` to prevent regressions.
2. **Keep Documentation Synchronized**:
   - Running `npm run build` or `npm run docs` executes `scripts/generate-codebase-doc.mjs`, which inspects files and updates `CODEBASE.md`.
   - Never manually overwrite `CODEBASE.md` sections that are generated by the script.
3. **Never Push Automatically**:
   - Keep all code changes local.
   - Do NOT run `git push` or trigger external deployments unless the user explicitly requests it.
